# 真实本地 Git（#41）

默认 `LocalGitProvider`，fake 仅由测试和演示种子显式注入。旧的非空模拟仓库显示“历史模拟”，不能初始化、迁移为真实仓库。空工作区显示“未初始化”。Git 检查执行、远端 PR、合并和生产部署均未实现，不会生成模拟成功证据。

## 部署与网页

安装 `/usr/bin/git`；设置 `GIT_REPOSITORY_ROOT` 为服务账户独占、预先创建的绝对目录。所有路径组件必须为真实目录，不允许符号链接。目录不要与用户上传、其他应用或宿主凭据共享。Docker 镜像安装 Git，Compose 使用 `/app/.data/git`；旧 volume 需由部署者预建该目录并设置所有权。数据库与该目录应一起备份和恢复，不能只恢复其中一个。

双方确认合同后，甲方分别授权乙方 `artifact`、`branch`、`commit`。乙方在工作区选择合同和里程碑，上传源文件（未绑定提交，SHA 为空），等待真实扫描放行；初始化仓库，从 main 创建分支，选择当前版本制品和目标相对路径，导入单个文件并提交。页面显示真实 SHA、来源 SHA-256、合同版本和真实 diff。缺少配置、缺少 Git、损坏仓库分别返回 `GIT_CONFIGURATION_REQUIRED`、`GIT_UNAVAILABLE`、`GIT_REPOSITORY_CORRUPT`；Git 失败返回 `GIT_OPERATION_FAILED`，不返回成功。

新增命令仍使用 `/api/workspaces/{contractId}/commands`，公共字段是 `action/version/requestKey`：

| action                  | 参数                          | 显式权限 |
| ----------------------- | ----------------------------- | -------- |
| initialize_repository   | 无                            | branch   |
| create_workspace_branch | branch                        | branch   |
| import_artifact         | branch、fileId、path、summary | commit   |

以上命令拒绝额外字段。客户端不能提供宿主路径、Git 命令、远端、SHA 或文件字节来伪造提交。制品读取重新鉴权，并检查当前合同、版本、真实扫描状态和实际字节校验和。源制品可以先于提交上传；既有绑定提交的交付制品校验保持不变。

## 隔离和恢复

仓库是 bare Git，只运行固定的 plumbing 命令，参数数组启动，无 shell、checkout、过滤器或代码执行。环境采用白名单，禁止系统/全局配置、替换对象、交互凭据、网络协议、hooks、helper、外部 diff 和 textconv。仓库配置必须等于服务生成的固定配置；遍历拒绝符号链接、硬链接和对象 alternates。分支限短 ASCII 名，目标路径拒绝绝对路径、路径穿越、Git 元数据路径及选项形态。部署目录是受信任边界，不支持另一个宿主进程并发修改其内容。

每个合同目录由服务端对合同 ID 哈希生成，每次写入复制出全新随机代际。旧代际永不修改。`BEGIN IMMEDIATE` 数据库写锁覆盖鉴权、Git 操作、工作区状态、请求去重、事件和外层审计发布；跨进程竞争串行化，锁竞争失败时不会返回成功。所有新代际文件和父目录 fsync 后，数据库才原子发布该代际引用。读取和重放都根据数据库引用验证 Git 完整性、分支 SHA、提交对象和来源文件字节。

- Git 失败：数据库回滚，旧代际仍有效。
- Git 完成、数据库或审计发布失败：数据库回滚，新目录成为孤立代际，不可被读取入口发现。
- 进程中断：SQLite 恢复未提交事务，保留旧引用；重试从已发布代际重新执行。
- 发布成功、响应丢失：相同主体、合同、请求键和参数重试返回已持久化结果，先重新鉴权并核验当前仓库；更改参数返回冲突。顶层 JSON 字段顺序不影响指纹。

代际和孤立目录目前保留，便于故障调查；没有自动垃圾回收。运维容量规划需考虑完整复制开销，不能在在线写入时人工删除目录。该最小实现适合小型本地交付，不是大仓库托管系统。

冻结契约：先确认有效身份及合同访问权，再返回合同状态错误。撤销委托的 Agent 收到 ForbiddenError；合法当事人的冻结新增写入收到 CONTRACT_NOT_ACTIVE。甲方本人仍可在非 active 状态撤销已有授权，争议管理员不因此获得私有仓库访问权。
